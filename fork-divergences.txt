# justified is what makes the test suite a meaningful guard rather than noise.
#
# Format: one pytest node id per line. Blank lines and #-comments ignored.

# --- our name contains a hyphen; the test's regex does not allow one --------
# test_hooks.py greps rebuild bodies with r"print\(f'\[([a-z ]+)\]" to check
# every log line uses one prefix. Our prefix is [halal-graphify]; the character
# class has no hyphen, so it matches nothing and the count assertion fails.
# The product is correct -- it does log a single consistent prefix.
tests/test_hooks.py::test_rebuild_bodies_arm_a_timeout_without_sigalrm

# --- deliberate behavioural divergence: we do not touch the other tool ------
# Upstream's installer removes any hook whose text contains "graphify", which
# assumes it is the only such tool on the machine. halal-graphify matches on
# its own name instead, so installing it never deletes hooks belonging to the
# original. That is required for the coexistence this fork promises, and it is
# exactly what this test asserts against.
tests/test_install_upgrade.py::test_claude_install_upgrades_stale_hook_payload
